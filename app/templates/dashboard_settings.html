Monitoring configuration

This self-hosted instance reads its monitoring settings from your local environment file.

To change network targets or the check interval, edit .env in your project directory and restart EthioNet Pulse.

HTTP services are configured with SERVICE_URLS. Separate multiple HTTP(S) endpoints with commas.

Telegram notifications use ENABLE_TELEGRAM_ALERTS, TELEGRAM_BOT_TOKEN, and TELEGRAM_CHAT_ID. Keep the token private and never commit .env.

Google sign-in is configured with GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET. The callback URL must match the URI configured in Google Cloud Console.
